# JayaFuture 

## Overview
JayaFuture adalah prototype platform career center untuk mahasiswa & alumni UPJ. 

## Repository Structure
- `/docs` : Semua dokumentasi proyek
- `/design` : File Figma & export mockup
- `/src/frontend` : Frontend prototype
- `/src/backend` : Backend API & integrasi
- `/tests` : Hasil testing & report

## How to Run
1. Frontend:
   - Open `index.html` di browser
2. Backend:
   - Jalankan `python api_server.py` (Python 3.x)
3. API Test:
   - Jalankan `python tests/api_test.py`

## Notes
- Code prototype hanya untuk demo, bukan produksi.
- Integrasi AI CV Generator menggunakan vendor API.
